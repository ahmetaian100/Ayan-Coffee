# Ayan Coffee Website

## How to run
1. Download and extract the ZIP archive.
2. Open the `ayan-coffee-site` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Features
- Fully English-language coffee shop website branded Ayan Coffee
- Classic coffee menu: Espresso, Latte, Cappuccino, Americano, Macchiato, and Mocha
- Individual photos, descriptions, prices, and selection buttons for each coffee
- Responsive mobile navigation, demo order form, dark/light theme toggle

Coffee photos are loaded from Unsplash, so an internet connection is needed. Prices and contact details are placeholders. The order form is for demonstration only and does not send real orders.

## Website Setup
The website is built with HTML, CSS, and JavaScript.
The website is published using GitHub Pages.
